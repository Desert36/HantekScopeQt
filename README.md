
HantekScopeQt
Universal Automotive Waveform Platform
Acquire, analyze, compare, convert and share automotive oscilloscope waveforms across multiple hardware ecosystems including Hantek, PicoScope, Autel MaxiScope and HScope.

Features:
- Fast waveform rendering
- PicoScope import/export
- Autel waveform import/export
- Windows support
- Linux support
- Android support
