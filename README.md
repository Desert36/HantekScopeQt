# HantekScopeQt

## Universal Automotive Test & Measurement Platform

Acquire, analyze, compare, convert and share automotive oscilloscope waveforms across multiple hardware ecosystems including Hantek, PicoScope, AutoScope, Autel MaxiScope and HScope.

HantekScopeQt is a professional multi-platform automotive diagnostics application that combines oscilloscope acquisition, waveform analysis, protocol decoding, digital multimeter functions, waveform conversion and long-term data logging within a single integrated environment.

### Key Features

#### Oscilloscope & Waveform Analysis
- High-performance GPU waveform rendering
- Multi-channel acquisition
- Real-time waveform analysis
- Advanced zoom and navigation
- Reference waveform comparison
- Vehicle waveform library
- Continuous streaming acquisition
- Unlimited CSV recording (disk space permitting)

#### Digital Multimeter
- Voltmeter
- Ohmmeter
- Continuity Tester
- RMS measurements
- Min / Max logging
- Trend monitoring
- CSV logging

#### Protocol Decoding

#### Probe Management

### Project Goal

HantekScopeQt aims to provide a hardware-independent automotive measurement platform capable of working across multiple oscilloscope ecosystems from a single application.

Instead of locking technicians into a single vendor ecosystem, HantekScopeQt focuses on interoperability, waveform portability and cross-platform support.
