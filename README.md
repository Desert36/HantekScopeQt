# HantekScopeQt

## Affordable Picoscope Alternative & Automotive Oscilloscope Software

HantekScopeQt is a very affordable, high-performance Picoscope alternative and automotive oscilloscope software, with performance comparable to Pico and Autel at a fraction of the cost. Acquire, analyze, compare, convert and share automotive oscilloscope waveforms across multiple hardware ecosystems including Hantek, PicoScope, AutoScope, Autel MaxiScope and HScope.

If you are looking for the **best scope software** or need to **import waveforms** from other diagnostic tools, HantekScopeQt gives you a complete oscilloscope and engine analysis environment at no cost.

---

## Key Features

### Oscilloscope & Waveform Analysis

- Affordable automotive oscilloscope software (Picoscope alternative)
- High-performance GPU waveform rendering
- Multi-channel acquisition
- Real-time waveform analysis
- Reference waveform comparison
- Vehicle waveform library
- Continuous streaming acquisition
- Unlimited CSV recording (disk space permitting)

### Waveforms Import & Compatibility

- **PicoScope (.psdata) Import / Export**
- Autel (.json) Import / Export
- Autel (.msdata) Import / Export
- AutoScope (.mwf) Import / Export
- HScope (.zip) Import / Export
- CSV / TSV / MAT Support
- Native HantekScopeQt Format

### Automotive Diagnostics

- 185+ Guided Diagnostics
- Cam / Crank Correlation
- Relative Compression Testing
- Injector Analysis
- Ignition Analysis
- Pressure Transducer Support
- Charging System Analysis
- Starting System Analysis
- Reference Waveform Comparison
- Vehicle Waveform Libraries

### Advanced Engine Timing Analysis

- Automatic Crank Tooth Counting
- Automatic Cam Tooth Counting
- Missing Tooth Detection
- Reluctor Wheel Identification
- Crank / Cam Synchronization Analysis
- Camshaft Phase Measurements
- Variable Valve Timing (VVT) Analysis
- Imported Waveform Correlation Analysis
- Sensor Pattern Simulation
- Mechanical Timing Visualization

### Protocol Decoding

- CAN, CAN FD, J1939, LIN, SENT, PSI5, I²C, I²S, 1-Wire, 10BASE-T1S

### Digital Multimeter

- Voltmeter, Ohmmeter, Continuity Tester, RMS Measurements, MIN / MAX Logging
