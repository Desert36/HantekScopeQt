# HantekScopeQt

## Universal Automotive Test, Measurement & Engine Analysis Platform

Acquire, analyze, compare, convert and share automotive oscilloscope waveforms across multiple hardware ecosystems including Hantek, PicoScope, AutoScope, Autel MaxiScope and HScope.

HantekScopeQt is a professional multi-platform automotive diagnostics application that combines oscilloscope acquisition, waveform analysis, protocol decoding, digital multimeter functions, guided diagnostics, crankshaft and camshaft correlation analysis, waveform conversion, sensor simulation and long-term data logging within a single integrated environment.

## Why HantekScopeQt?

Unlike traditional oscilloscope software tied to a single manufacturer ecosystem, HantekScopeQt focuses on:

- Hardware Independence
- Waveform Portability
- Cross-Platform Support
- Automotive Diagnostics
- Engine Timing Analysis
- Multi-Vendor Compatibility
- Guided Diagnostic Workflows

The goal is to provide technicians with a complete automotive test and measurement environment capable of working across multiple oscilloscope ecosystems from a single application.

---

## Project Goal

HantekScopeQt aims to bridge the gap between electrical waveform analysis and real engine behavior.

By combining oscilloscope functionality, waveform interoperability, guided diagnostics and animated mechanical timing analysis, technicians can move beyond simply viewing waveforms and gain a deeper understanding of engine operation and synchronization.
