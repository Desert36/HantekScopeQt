Universal Waveform Import & Export

HantekScopeQt makes it easy to import waveform files from other diagnostic platforms and export waveform data for analysis. Move captures freely between PicoScope, Autel, HScope and ATS-style tools without losing data, and never worry about being locked out of your own files.

Import Waveform Formats

  • .psdata (PicoScope)
  • .msdata / .json (Autel)
  • .zip (HScope)
  • ATS-style waveform captures
  • .mwf (AutoScope)
  • .csv / .tsv / .mat
  • .hantek (native)

Export Waveform Formats

  • CSV (for Excel and spreadsheets)
  • TSV
  • MAT (for MATLAB)
  • Native HantekScopeQt format

Auto Waveforms

HantekScopeQt supports auto waveforms — imported captures load automatically with all channels displayed, ready for analysis. No manual channel setup required.

How to Import a Waveform

  1. Download and launch HantekScopeQt
  2. Choose Import Waveform
  3. Select your file (.psdata, .msdata, .json, .zip, .mwf, .csv)
  4. Analyze, compare, or export to CSV, TSV or MAT

Frequently Asked Questions

How do I import waveforms into HantekScopeQt?

Choose Import Waveform and select your file. HantekScopeQt supports PicoScope .psdata, Autel .msdata and .json, HScope .zip, ATS, AutoScope .mwf, CSV, TSV and MAT.

Can I export waveforms to CSV?

Yes. HantekScopeQt exports waveform data to CSV, TSV and MAT for analysis in Excel, MATLAB and other tools.

What are auto waveforms?

Auto waveforms automatically load and display multi-channel captures from imported files, so all channels appear instantly without manual setup.
